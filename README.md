# Coderbunch business apps

18 independent desktop applications for everyday business work. This repository hosts public download information and binary release assets; application source is private.

## Release status

RC3 is undergoing evaluation. There is no stable public download yet. The maintainer's draft release contains the Windows x64 portable packages and SHA-256 checksums; drafts are visible only to authorized repository users.

The automated RC3 checks passed 458 application tests in source, executables and extracted ZIPs on the development host, plus 27 release-tool tests. Separate clean-machine, business-owner, visual/accessibility and physical printer/scanner acceptance remain pending. These are unsigned portable candidates, not store-certified installers.

## Using future downloads

Extract the complete product ZIP into a short writable folder. Run its product-named EXE and keep `_internal` beside it. Python is not required. Start with samples or disposable copies. Back up app records before updating, and keep the previous version until data and workflows are verified. Portable apps have no automatic updater or installer.

## Support

Report problems or feature requests through [GitHub Issues](https://github.com/coderbunch/business-apps-releases/issues). Include the application name, version and steps to reproduce. Use synthetic examples rather than posting private business records.

Source visibility and third-party component licenses are separate: each downloadable package retains its third-party notices. No public source-code license is granted by this repository.
